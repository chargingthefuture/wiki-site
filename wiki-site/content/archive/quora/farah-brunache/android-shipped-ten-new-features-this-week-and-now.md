Android shipped ten new features this week, and now mobile and desktop are at feature parity.

Here's what's new on the phone: you can react with emojis to Commons posts, reply directly to specific messages with an unread divider. Directory profiles show who's online and display trust signals. Foundation providers can list their skills. SocketRelay requests now expire after 28 days and can be re-posted.

If you mostly use mobile, you can now do the same work as desktop users without switching devices. The interface stays consistent.
