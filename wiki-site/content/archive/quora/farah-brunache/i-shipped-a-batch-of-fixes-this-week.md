I shipped a batch of fixes this week. LightHouse listings now work with multiple currencies — so if you're listing a space, you can set the price in whatever currency makes sense for where you are. You can also edit your own listing directly instead of going through an approval flow.

Chyme's raise-hand feature now sticks with you as you move between rooms, rather than resetting. That means your hand stays up and people know you're waiting to speak.

I also cleaned up the mobile top bar so it displays properly, and we fixed some database indexes so Service Credits mint reliably under load.

The code lives at [GitHub - chargingthefuture/chargingthefuture: world's first psyop-free economy](https://www.quora.com/_/redirect?sig=ce85c0&url=https://github.com/chargingthefuture/chargingthefuture) if you want to see the details.
