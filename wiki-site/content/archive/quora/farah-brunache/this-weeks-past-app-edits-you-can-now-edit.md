This week’s past app edits

You can now edit your own messages in the Commons. Click Edit next to Delete, type your correction in the compose box, and send — it posts as a new message with a fresh timestamp, so edits stay visible and can be moderated. Delete and repost is now the edit model everywhere on the platform: Commons, Chyme, and the shared chat used by Foundation, Lighthouse, and other plugins.

Chyme's chat window now scrolls in place instead of stretching the page taller with each message. The mute button moved to the top of the room, so you can reach it without scrolling. Web browsers now hold a screen wake lock during audio calls so the display doesn't sleep mid-conversation.

In-app notifications now jump to the message when you tap Open — if the message is old, the app loads the surrounding window so you see it in context.
