I just shipped a batch of fixes that smooth out the everyday experience on Charging the Future.

Chyme's guest listening now works without bumps — if you want to listen to the live room before signing in, it just works. The refresh button actually refreshes. On mobile, the interface stays clear. We fixed how tokens expire so you don't hit weird stops.

LightHouse cards now show only the fields that matter. Blank spaces are gone, so you scan matches faster. Every plugin now shares the same footer design, so the platform feels like one coherent tool instead of a bunch of separate pieces.

We also fixed some backend stuff: directory admins can update profiles without errors, governance ticket IDs are stored correctly so automated mints don't fail, and if a reward gets stuck, our tools can retry it and show you exactly what went wrong.

The code lives at [GitHub - chargingthefuture/chargingthefuture: world's first psyop-free economy](https://www.quora.com/_/redirect?sig=ce85c0&url=https://github.com/chargingthefuture/chargingthefuture) — it's all open source.
