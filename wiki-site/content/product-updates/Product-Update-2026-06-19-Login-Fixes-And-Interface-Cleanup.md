# Product Update: Login Fixes, Interface Cleanup, and Self-Hosting

**Date:** June 19, 2026

## What Shipped

### Login Performance
Fixed a database issue that was slowing down login. The system now handles timestamps correctly so the daily login index builds without errors.

### Cleaner Home Screen
The home page right rail now leads with chat first. We removed filler content about pricing and immediate placement—if you need housing help, you can find it through chat. Mobile users also see the "Survivor to Thriver" hero section removed on smaller screens so the page loads faster and cleaner.

### LightHouse Self-Hosting
Members using LightHouse can now set up their own instance directly. You don't need a separate host profile anymore. The setup process handles runtime configuration safely, so you won't see errors if something can't be read right away.

### Feed as Single Source
Announcements now come through the main Feed only. We removed per-plugin announcement systems so you see updates in one place, not scattered across multiple tabs.

## Why It Matters

Logins should work fast. Your home screen should show you what you actually use—not templates or sales language. If you want to host your own copy of LightHouse, you can do it now without extra steps. And when you check for updates, you know exactly where to look.
