# Android Feature Parity Wave

**2026-06-22**

Android caught up to desktop this week. Ten features shipped to mobile.

## What Shipped

- **Emoji reactions** on Commons community posts — react with a single emoji to any message.
- **Reply-to-message** + unread divider in Commons — reply directly to a specific post and see where new messages start.
- **Peer Programming listen-in** for admins — admins can now manage all cohorts and listen in on peer programming sessions on mobile.
- **Foundation offered-skills** on mobile — Foundation providers can list the skills they offer.
- **@comic applicable-plugin links** — the @comic training dashboard now shows which plugins apply to each training example.
- **Training-examples counter** on mobile @comic review dashboard — see how many examples you've reviewed at a glance.
- **Member presence + trust panel** on directory profiles — see who's online and view trust signals when you look up a member.
- **Pending-skill chips** + Foundation call-to-action on mobile directory — see what skills members are working toward.
- **SocketRelay 28-day expiry** + re-post — SocketRelay requests now expire after 28 days; you can re-post if needed.
- **Retry pending rewards** control in Unlock admin — admins can retry failed reward unlocks on mobile.
- **Trust surface is now signal-only** — the Trust surface on mobile shows signals without the verification chip, keeping the interface clean.

## Why It Matters

Mobile users can now do the same work as desktop users. Whether you're in the Commons, running training, matching with peers, or managing as an admin, you have the same tools in your pocket. The interface stays consistent across devices, so switching between phone and computer doesn't mean relearning where things are.
