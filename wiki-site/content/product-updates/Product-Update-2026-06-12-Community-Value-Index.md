# Product Update: Community Value Index and mutual aid tracking

**Date:** June 12, 2026

## What Shipped

Two updates landed on the platform:

1. **Free as a value type.** You can now log mutual aid and unpaid support as Free value. These contributions show up in the Community Value Index so the platform counts what you give without money.

2. **Shared currency selector.** A new component lets you switch how Community Value Index figures display—pick the currency that makes sense for your region or preference.

We also fixed copy in TrustTransport to be clearer when a ride request is still waiting for a match, and made sure the "Book a Ride" button actually submits.

## Why It Matters

Mutual aid is work. When you help a neighbor with food, childcare, or skills, that matters to the economy even though no money changes hands. Logging it as Free value means your contributions are visible and counted. The currency selector makes data readable for people across different regions.

## Technical Notes

- Free is now a recognized value type in the Community Value Index
- The shared currency selector is available as both a UI component and API endpoint
- TrustTransport trip matching status messaging is clearer
- GDP inventory aligns with Community Value Index structure
