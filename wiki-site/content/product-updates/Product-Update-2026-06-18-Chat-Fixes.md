# Product Update: Chat Fixes

**Date:** June 18, 2026

## What Shipped

Three improvements landed in the home chat:

1. **Concierge replies now sort to the bottom.** When the concierge responds in chat, the message appears below user messages so you see the conversation flow in order.
2. **Auto-scroll to latest.** The chat automatically scrolls to show the newest message, so you don't have to scroll manually each time someone replies.
3. **Contributions icon updated.** The Contributions section now uses a gift icon instead of a heart. This keeps the interface clearer since hearts appear elsewhere in the app.

## Why It Matters

Chat should feel predictable. You expect replies to land where they belong and the newest message to be in view. These changes make the home chat feel more like a real conversation—organized and easy to follow.
