# Product Update: Skills Search, Directory Profiles, and Refresh Controls

**Date:** July 14, 2026

## What Shipped

- **Keyword search in SkillsHunt Scout**: Type to find skills instead of scrolling through the full list. Narrows down matches as you type.
- **Create your own directory profile**: Members can now build their provider profile in the directory without waiting for an admin to set it up.
- **Pull-to-refresh everywhere**: Refresh controls now work on all mobile screens (Android and web) so you can pull down to get the latest data instantly.
- **Advocates occupation added**: "Advocates / Awareness Raisers" is now available in the skills taxonomy for members who do this work.
- **Fixed empty states**: The Foundation provider browser now shows context-aware messaging when no results match your search.
- **Mobile display fixes**: Avatar clipping in the Commons mobile bar is fixed. Refresh button now reads correctly to screen readers. Admin buttons removed from the skills taxonomy browser.

## Why It Matters

Searching through skills used to mean clicking through a long list. Keyword search cuts that down to seconds. Creating your own directory profile means you control how you show up to others looking for your expertise—no waiting, no middleman. These small changes add up to a platform that moves faster and puts control in your hands.
