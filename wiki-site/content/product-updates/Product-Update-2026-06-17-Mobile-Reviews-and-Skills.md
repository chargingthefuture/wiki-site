# Product Update: June 17, 2026

## What Shipped

- **Phone-friendly review screen.** The AI answer review interface now works on mobile devices. You can review answers on whatever screen you're using.
- **Cleaner skill profiles.** When you look at another survivor's profile in the Directory, you only see the skills they're actively offering. The backend now pulls this directly from the Directory instead of keeping a separate copy.
- **Operator dashboard rename.** We renamed the operator screens from "console" to "dashboard" so the language is clearer.
- **Weekly Performance hidden.** Weekly Performance metrics are now admin-only and don't show in user-facing apps.
- **Foundation skill offers.** Providers can now opt in to offer specific skills, with a UI for picking which ones and filtering by skill type.
- **Workforce data lives.** Workforce profiles now read directly from Directory data instead of syncing a copy, so everything stays in sync.

## Why It Matters

These changes make the platform easier to use on phones, keep your profile data accurate without duplication, and give you more control over which skills you're advertising. The code is cleaner too, which means fewer moving parts to break.
