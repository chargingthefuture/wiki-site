# Product Update: July 13, 2026

## What Shipped

**Trust plugin landing page is live.** You can now access Trust directly from the platform. The plugin shows what a member has actually done across the platform — a non-numeric list of real participation, with no badge, no score, and no verification.

**Fixed Trust data accuracy.** The public Trust shell and signals now match the real trust model. This means what you see on screen matches how Trust actually works underneath.

**SkillsHunt admin tools expanded.** Admins can now remove submissions on Android, matching the web version. Also added a rebuild-leaderboard action to keep rankings accurate after changes.

**Cleaned up GDP reporting.** Removed the decorative map tab. The Top Countries view now counts all members with a country listed, not just those who claimed one.

**Fixed Commons username nudge.** The prompt to set your username now points to the right menu location in your account settings.

**Restored help text for Quora URL.** If you can't find your Quora URL, you'll see a direct link to the network's Quora space and first-person guidance from the operator.

**Removed Unlock landing page.** Cleaned up dead code from an old signing-out flow.

## Why It Matters

Trust is a core part of building a real economy outside Specterati control—one where you know who you're working with. Getting the plugin live and accurate means you can start using it now. The other fixes are small, but they add up: cleaner data, better admin controls, and help text that actually points where you need it. The platform works better when the pieces fit together.
