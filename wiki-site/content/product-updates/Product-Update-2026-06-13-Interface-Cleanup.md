# Product Update: Interface Cleanup and Mobile Fixes

**Date:** June 13, 2026

## What Shipped

We made several changes to streamline the app and fix issues on mobile:

- **Removed duplicate screens.** The app list and profile gates were showing twice or blocking progress unnecessarily. These are gone.
- **Fixed mobile navigation.** The Admin link now appears in the mobile nav drawer, and the Hub layout is compact on phones so chat doesn't get crowded.
- **Updated plugin descriptions.** Plugin copy now matches the landing page, so you see consistent information everywhere.
- **Made forms more accessible.** Icon-only buttons now have labels, and loading states are announced properly.
- **Simplified chat tabs.** We removed non-functional and misleading chat options.
- **Added a Share Link control.** You can now see, copy, and share links in one place across the app.
- **Improved loading screens.** Fast loads no longer flash a loading state, and the screen stays centered and announced to assistive tech.

## Why It Matters

A simpler interface means less friction when you're moving through the app. Mobile users get a proper experience instead of a squeezed desktop layout. Accessible forms and labels make the app work with screen readers and keyboard navigation. Consistent descriptions help you understand what each tool does without hunting for information.
