# Product Update: June 25, 2026

## What Shipped

**Service Credits wallet transaction history**: The wallet displays your complete transaction record—each mint, burn, and balance change is now visible. You can see what happened and when.

**Foundation instant call billing**: Instant 1:1 calls now bill per minute. The call screen shows your credit balance and how many minutes you have available before each call starts. When a call ends, the transaction appears in your wallet history.

**Directory skills search by type**: Search the directory by occupation category. Filter for mentors, engineers, legal advisors, or any skill type to narrow results.

**Game Designers occupation**: Added Game Designers / Developers to the skills taxonomy so you can list this capability in your profile.

**Admin demo mode banner**: Operators see a warning when admin tools are running on demo data, so test environments stay separate from live action.

**Admin action feedback**: When you mint or burn credits as an admin, the result now displays at the action itself instead of requiring a separate lookup.

## Why It Matters

Transaction history lets you track your credits at a glance. Per-minute call billing is honest and predictable—you know the cost before you connect. Search filters and the new occupation option make it easier to find the right person. Admin tools now give clearer, faster feedback so operators can work without second-guessing.
