## What Shipped

**SocketRelay post auto-expiry and re-post button.** Posts now automatically expire after 28 days. A re-post button appears when a post expires, letting you list it again without rewriting it.

**Mobile display fixes.** The Peer Programming admin date field no longer overflows on iOS. LevelUp stat cards and cohort grid now fit properly on mobile screens. The Peer Programming admin now shows all cohorts across weeks instead of just the current week.

**Plugin chat polls and reminders.** Added polls and message reminders to the plugin chat panel—paired with your Direct Line transactions.

**Beacon livestream API integration.** Wired the Beacon livestream feature against Stream Video's REST API for live event support in the Commons.

## Why It Matters

Keeping posts fresh matters when you're searching for matches or resources. The re-post button saves you time—no need to delete and rewrite. Mobile users on iOS can now access Peer Programming admin and stats without the interface breaking. Polls and reminders in Direct Line chat make it easier to coordinate with matched peers or service providers.
