# Peer Programming Weekly Assignment Now Runs Automatically

## What Shipped

Peer Programming cohort assignment now happens on schedule without manual intervention. Each week, the system identifies survivors ready for a match, pairs them, and sends Direct Line invites to both members. You'll see the assignment posted in the Commons so the whole community knows a new group is forming.

## Why It Matters

Manual scheduling created gaps and delays. Automation means cohorts start on a predictable rhythm. Survivors can count on regular pairing cycles and know when to expect a match.

The build also cleaned up how the app reads its environment settings, removing redundant configuration options that were creating confusion.
