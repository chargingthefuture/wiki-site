# Admin Dashboard Redesign

## What Shipped

We rebuilt every admin surface to match the design system. This includes:

- LightHouse admin (with cancel matching and announcements)
- Workforce admin
- GDP admin
- Feed and Announcements admin
- TrustTransport admin
- SocketRelay admin
- Foundation admin
- Unlock admin

Each page now pulls real data and works the same way. You can also hide and restore property listings in LightHouse.

We fixed Chyme chat presence so people don't show up twice when they join, and they properly leave when they disconnect. On phones, the Chyme header is cleaner now—the refresh button stays where you need it.

One more fix: the Unlock approval process won't fail if the incentive step runs into trouble.

## Why It Matters

When admin tools look and work the same way, you spend less time learning and more time doing the work. You know where to find things. You can trust the data in front of you.

Chyme chat now shows who's actually in the room, which means you're not confused about who can see your message. The smaller header on phones means more space for what you're trying to read or write.
